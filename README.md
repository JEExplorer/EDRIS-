# افغان بیزنس پرو | Afghan Business Pro

نسخه توسعه‌یافته آفلاین برای مدیریت کسب‌وکارهای کوچک.

## امکانات موجود در این نسخه
- داشبورد شاخص‌های فروش، سود تخمینی، موجودی و بدهی
- ثبت، ویرایش، حذف و جستجوی محصولات، فروش، خرید، مصارف، بدهی‌ها، مشتریان، تأمین‌کنندگان و کارمندان
- ثبت تعداد، قیمت فروش، قیمت خرید، موجودی حداقل و بارکد محصول
- کسر موجودی هنگام فروش و افزایش موجودی هنگام خرید (برای محصولی با نام دقیقاً یکسان)
- محاسبه مبلغ فروش/خرید و مانده پرداخت
- هشدار محصولات کم‌موجود
- گزارش جمع فروش، خرید، سود ناخالص ثبت‌شده، مصارف و سود خالص تخمینی
- خروجی CSV برای هر بخش
- نسخه پشتیبان JSON و بازیابی آن
- نام فروشگاه و واحد پول قابل تنظیم
- ذخیره‌سازی محلی و کارکرد آفلاین

## راه‌اندازی در Windows
1. Flutter SDK و Android Studio را نصب کن و مطمئن شو دستور `flutter doctor` اجرا می‌شود.
2. فایل ZIP را کامل Extract کن.
3. روی `setup_windows.bat` دوبار کلیک کن.
4. برای ساخت APK:
   `flutter build apk --release`
5. فایل خروجی:
   `build/app/outputs/flutter-apk/app-release.apk`

## ساخت با GitHub Actions
کل محتویات این پوشه را در ریشه مخزن GitHub آپلود کن. Workflow از شاخه `main` اجرا می‌شود و APK را به‌عنوان Artifact ذخیره می‌کند.

## نکات مهم و محدودیت‌های فعلی
- این نسخه یک سیستم آفلاین تک‌دستگاهی است؛ همگام‌سازی چند کاربره/چند شعبه‌ای، ورود کاربران و سطح دسترسی، اتصال بانکی، چاپگر حرارتی، فاکتور PDF، مالیات پیشرفته و حسابداری دوبل هنوز پیاده‌سازی نشده‌اند.
- ویرایش یا حذف یک معامله قدیمی، گردش موجودی را به‌صورت خودکار بازسازی نمی‌کند؛ برای جلوگیری از اختلاف موجودی، تراکنش‌های ثبت‌شده را با دقت اصلاح کن.
- فروش با نام محصول دقیقاً یکسان به محصول وصل می‌شود. در نسخه بعد بهتر است انتخاب محصول از فهرست و شناسه ثابت اضافه شود.
- سود تخمینی بر پایه بهای تمام‌شده‌ای است که هنگام ثبت فروش از محصول خوانده می‌شود. این ابزار جایگزین حسابداری حرفه‌ای یا مشاوره مالیاتی نیست.
- اطلاعات روی دستگاه ذخیره می‌شود؛ مرتب نسخه پشتیبان بگیر و فایل آن را امن نگهدار.
- این بسته در محیط تولیدکننده با Flutter SDK اجرا و APK آن کامپایل نشده است؛ پس از راه‌اندازی، `flutter analyze` و تست روی گوشی واقعی ضروری است.
